PUBG: Battlegrounds est un jeu vidéo multijoueur en ligne de type battle royale développé et édité par PUBG Studios. Il est disponible en accès anticipé sur Microsoft Windows à partir du 23 mars 2017, et la version 1.0 du jeu est sortie le 20 décembre 2017.

  • Développeurs : Krafton, PUBG Studios, Tencent Mobile International Limited, LightSpeed Studios
  • Plates-formes : Android, Microsoft Windows, PlayStation 4, Xbox Series, Xbox One
  • Distinctions : Game Award du meilleur jeu multijoueur
  • Concepteur : Brendan Greene
  • Date de sortie initiale : 23 mars 2017
  • Nominations : Game Award du meilleur jeu de l'année
  • Genres : Battle royale, Jeu de tir, Jeu en ligne massivement multijoueur, Jeu d'action-aventure

Call of Duty ou COD est une série de jeux vidéo de tir à la première personne sur la guerre, dont le premier opus est publié en 2003 par le studio Infinity Ward et l'éditeur Activision. Les épisodes prennent place lors de la Seconde Guerre mondiale ou lors de conflits modernes fictifs.

  • Développeurs : Activision, Treyarch, Infinity Ward, Raven Software
  • Concepteurs : Mohammad Alavi, David Vonderhaar, Jacob Minkoff
  • Éditeurs : Activision, Activision Blizzard, Nokia, VNG, 1C Company

Fortnite est un jeu en ligne développé par Epic Games sous la forme de différents modes de jeu qui partagent le même gameplay général et le même moteur de jeu.

  • Développeurs : Epic Games, People Can Fly
  • Date de sortie initiale : 21 juillet 2017
  • Distinctions : Game Award du meilleur jeu multijoueur
  • Plates-formes : PlayStation 5, GeForce Now, XCloud
  • Genres : Battle royale, Jeu de tir à la première personne
  • Éditeurs : Epic Games, Gearbox Software
  • Nominations : BAFTA Games Award du meilleur jeu multijoueur
